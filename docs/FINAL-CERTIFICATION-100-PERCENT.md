| Table | Before | After |
|-------|--------|-------|
| calendar_events | `true` | `created_by = auth.uid()` |
| incident_snapshots | `true` | `auth.uid() IS NOT NULL` |
| joint_missions | `true` | `auth.uid() IS NOT NULL` |
| logistics_operations | `true` | `organization_id` check |
| profiler_sessions | `true` | `user_id = auth.uid()` |

| restore_reports | `true` | `restored_by = auth.uid()` |
