# 🚀 NAUTI ONE - QUICK START GUIDE

## Início Rápido (5 minutos)

### 1. Acessar o Sistema

**URL de Preview**: https://id-preview--ead06aad-a7d4-45d3-bdf7-e23796c6ac50.lovable.app

**URL de Produção**: https://travel-hr-buddy.lovable.app

### 2. Criar Conta

1. Acesse `/auth`
2. Clique em "Criar Conta"
3. Preencha seu email e senha
4. Confirme o email recebido

### 3. Primeiro Acesso

Após login, você será direcionado para:
- **Central de Comando** (`/dashboard/central-comando`)

### 4. Navegação Principal

O sidebar esquerdo contém 17 seções:

1. **Central de Comando** - NOC/SOC, Alertas, KPIs
2. **Operações Marítimas** - Frota, Viagens, Rotas
3. **Manutenção** - Preditiva, Ordens de Serviço
4. **Operações Submarinas** - Sonar, Drones, ROVs
5. **IA & Automação** - 16 Agentes IA, Voice
6. **Inteligência** - ML, Predições, Insights
7. **Telemetria** - IoT, Sensores, Satélites
8. **APIs & Integrações** - REST API, Webhooks
9. **Relatórios & Documentos** - EDMS, Templates
10. **Comunicação** - Chat, Alertas, Notificações
11. **Auditorias & Compliance** - SGSO, MLC, ISM
12. **Diagnósticos** - Health Check, Métricas
13. **RH & Pessoas** - Crew, Payroll, Training
14. **Treinamentos** - LXP, Certificações
15. **Finanças** - Contabilidade, Procurement
16. **Viagens & Logística** - Weather, Routes
17. **Ferramentas Avançadas** - PWA, Analytics

### 5. Funcionalidades Principais

#### Voice Assistant
- Clique no ícone de microfone
- Fale "Mostrar frota" ou "Status de manutenção"

#### AI Chat
- Disponível em cada módulo
- Pergunte sobre compliance, procedimentos, etc.

#### Offline Mode
- Sistema funciona sem internet
- Dados sincronizam automaticamente

### 6. API REST

**Base URL**: `https://vnbptmixvwropvanyhdb.supabase.co/functions/v1/api-v1`

**Autenticação**: Header `X-API-Key: sua-chave`

**Endpoints**:
- `GET /vessels` - Lista embarcações
- `GET /crew` - Lista tripulação
- `GET /documents` - Lista documentos
- `GET /maintenance` - Lista manutenções
