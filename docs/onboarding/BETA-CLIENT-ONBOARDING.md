# 🚢 Nautilus One - Beta Client Onboarding Guide

## Welcome to Nautilus One v4.0

Parabéns por fazer parte do programa beta do Nautilus One - a plataforma completa de gestão marítima com IA integrada.

---

## 📋 Checklist de Onboarding (15 minutos)

### Passo 1: Acesso Inicial
- [ ] Acesse: https://travel-hr-buddy.lovable.app
- [ ] Faça login com suas credenciais fornecidas
- [ ] Confirme acesso ao dashboard principal

### Passo 2: Configuração da Organização
- [ ] Acesse **Configurações > Organização**
- [ ] Preencha dados da empresa (nome, CNPJ, contato)
- [ ] Configure logo e identidade visual

### Passo 3: Cadastro de Embarcações
- [ ] Acesse **Frota > Embarcações**
- [ ] Adicione sua primeira embarcação (IMO, nome, tipo)
- [ ] Configure sensores e alertas

### Passo 4: Cadastro de Tripulação
- [ ] Acesse **RH > Tripulantes**
- [ ] Importe planilha de tripulantes ou cadastre manualmente
- [ ] Configure certificações e documentos

### Passo 5: Ativação de Módulos
- [ ] **PEOTRAM**: Compliance MLC 2006
- [ ] **PEO-DP**: Programa de DP
- [ ] **GMUD**: Gestão de Mudanças
- [ ] **MMI**: Manutenção Inteligente

## 🤖 Assistente de Voz "Hey Nauti"

### Comandos Suportados
```
"Hey Nauti, qual o status da frota?"
"Hey Nauti, mostre alertas críticos"
"Hey Nauti, gere relatório PEOTRAM"
"Hey Nauti, agende manutenção do motor"
"Hey Nauti, calcule horas de descanso"
```

### Ativação
1. Clique no ícone de microfone (canto inferior direito)
2. Diga "Hey Nauti" seguido do comando
3. Aguarde a resposta por voz ou texto

## 📱 Acesso Mobile

O Nautilus One é uma PWA (Progressive Web App) otimizada para dispositivos móveis:

1. Acesse pelo navegador mobile
2. Clique em "Adicionar à tela inicial"
3. Use como app nativo

**Funciona offline!** Dados sincronizam automaticamente quando há conexão.

---

## 🔐 Segurança

- **Multi-tenant**: Seus dados são isolados de outras organizações
- **RLS**: Row Level Security em todas as tabelas
- **Criptografia**: Dados em trânsito e em repouso
- **Audit Logs**: Todas as ações são registradas

## 🐛 Reportando Bugs (Beta)

Como cliente beta, seu feedback é essencial:

1. **Captura de Tela**: Tire screenshot do problema
2. **Reprodução**: Descreva os passos para reproduzir
3. **Impacto**: Classifique (crítico/alto/médio/baixo)
4. **Envio**: Use o botão "Reportar Bug" no menu
