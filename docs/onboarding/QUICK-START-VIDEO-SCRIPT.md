## Notas de Produção

### Estilo Visual
- Paleta de cores: Azul marinho (#0A1628), Verde oceano (#10B981)
- Tipografia: Inter para texto, Montserrat para títulos
- Transições suaves (fade 0.3s)

### Música
- Background: Música corporativa calma, sem letra
- Volume: -20dB do pico da narração

### Narradores
- Principal: Voz masculina, tom profissional mas acolhedor
- Alternativa: Voz feminina para variação entre vídeos

### Duração Total
- Série completa: ~12 minutos
- Cada vídeo independente para consumo individual
