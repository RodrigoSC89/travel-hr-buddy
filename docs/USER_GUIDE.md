# 📖 NAUTI ONE v4.0 - USER GUIDE

## 🚀 Getting Started

### First Login

1. Navigate to `https://travel-hr-buddy.lovable.app`
2. Click "Entrar" (Login)
3. Enter your credentials
4. Select your organization

### Dashboard Overview

The main dashboard provides:
- **Real-time metrics** for fleet and crew
- **Compliance alerts** requiring attention
- **AI recommendations** for operations
- **Quick actions** for common tasks

---

## 🎯 Core Modules

### 1. Command Center `/central-comando`

The unified control hub for all operations.

**Features:**
- Real-time fleet visualization
- AI agent status monitoring
- Decision automation
- Alert management

**Quick Actions:**
- View fleet status
- Monitor compliance
- Access AI insights
- Manage alerts

---

### 2. PEOTRAM Audits `/peotram`

Petrobras DP vessel audit management.

**Key Functions:**
- **13 Elements:** Complete PEOTRAM checklist
- **AI Evidence:** Auto-generate audit evidence
- **Voice Input:** Speak to create records
- **PDF Export:** Professional reports

**How to Use:**
1. Select vessel
2. Choose audit element
3. Complete checklist items
4. Generate AI evidence
5. Export PDF report

---

### 3. PEO-DP Excellence `/peo-dp`

Operational Excellence Program management.

**Features:**
- Compliance scoring dashboard
- Gap analysis
- Improvement tracking
- Benchmark comparisons

---

### 4. Crew Management `/crew-management`

Complete crew administration.

**Functions:**
- Crew roster management
- Document tracking
- Certification monitoring
- Schedule planning

**Adding Crew:**
1. Click "Adicionar Tripulante"
2. Fill personal information
3. Upload documents
4. Assign to vessel
5. Save profile

---

### 5. Payroll System `/folha-pagamento`

Brazilian payroll with INSS/IRRF compliance.

**Features:**
- Automatic tax calculations
- PDF payslip generation
- Excel export
- Historical records

**Generating Payroll:**
1. Select period
2. Review calculations
3. Approve amounts
4. Generate payslips
5. Export reports

---

### 6. Fleet Manager `/fleet-manager`

Vessel fleet administration.

**Features:**
- Vessel profiles
- Real-time tracking
- Maintenance schedules
- Document management

---

### 7. Document Hub `/document-hub`

Centralized document management.

**Features:**
- Upload/download files
- OCR text extraction
- AI document search
- Expiration alerts

**Uploading Documents:**
1. Click "Upload"
2. Select file(s)
3. Choose category
4. Add metadata
5. Submit

---

Business intelligence dashboards.

## 🤖 AI Features

### AI Assistant `/assistente-ia`

Your intelligent maritime assistant.

**Capabilities:**
- Answer maritime questions
- Generate reports
- Analyze documents
- Provide recommendations

**Using AI:**
1. Type your question
2. Press Enter or click Send
3. Review AI response
4. Request clarification if needed

### Voice Commands

Available in PEOTRAM and other modules:
- Click microphone icon
- Speak your command
- Review transcription
- Confirm action
